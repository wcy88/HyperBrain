## 1. 快速开始指南

### 1.1 系统要求

| 项目 | 最低要求 | 推荐配置 |
|------|----------|----------|
| 操作系统 | Windows 10 / Linux / macOS | Windows 11 / Ubuntu 22.04 |
| Python | 3.11+ | 3.12+ |
| 内存 | 4GB | 8GB+ |
| 硬盘空间 | 2GB | 5GB+ |
| 网络 | 可选 | 用于在线模型 |

### 1.2 安装步骤

#### 方法一：源码安装

```bash
# 1. 克隆仓库
git clone <repository-url>
cd hyperbrain

# 2. 创建虚拟环境
python -m venv venv

# 3. 激活虚拟环境
# Windows:
venv\Scripts\activate
# Linux/macOS:
source venv/bin/activate

# 4. 安装依赖
pip install -r requirements.txt

# 5. 配置环境变量
copy .env.example .env
# 编辑 .env 文件，填写 API 密钥
```

#### 方法二：使用打包版本

1. 下载对应平台的打包文件
2. 解压到目标目录
3. 复制 `.env.example` 为 `.env` 并配置
4. 运行启动脚本

### 1.3 首次启动

#### GUI 模式

```bash
# 源码启动
python -m hyperbrain.app --mode gui

# 或打包版本
HyperBrain.exe --mode gui
```

#### CLI 模式

```bash
# 源码启动
python -m hyperbrain.main --mode cli

# 或打包版本
HyperBrain.exe --mode cli
```

### 1.4 快速配置

1. 复制 `.env.example` 为 `.env`
2. 填写至少一个模型 API 密钥：
   - OpenAI API Key
   - Anthropic API Key
   - Google API Key
   - 或配置本地 Ollama 模型
3. 保存并重启系统

## 4. 配置指南

### 4.1 环境变量配置

创建 `.env` 文件，配置以下变量：

```env
# ================================
# 系统基础配置
# ================================
DEBUG=false
DATA_DIR=data
LOG_DIR=logs

# ================================
# OpenAI 配置
# ================================
OPENAI_API_KEY=your_openai_api_key_here
OPENAI_MODEL=gpt-4

# ================================
# Anthropic 配置
# ================================
ANTHROPIC_API_KEY=your_anthropic_api_key_here
ANTHROPIC_MODEL=claude-3-opus-20240229

# ================================
# Google 配置
# ================================
GOOGLE_API_KEY=your_google_api_key_here
GOOGLE_MODEL=gemini-pro

# ================================
# Ollama 本地模型配置
# ================================
OLLAMA_BASE_URL=http://localhost:11434
OLLAMA_MODEL=llama2

# ================================
# 模型默认参数
# ================================
MODEL_TEMPERATURE=0.7
MODEL_MAX_TOKENS=2048
MODEL_TIMEOUT=60

# ================================
# 记忆层配置
# ================================
MEMORY_VECTOR_DIM=1536
MEMORY_MAX_SHORT_TERM=100
MEMORY_SIMILARITY_THRESHOLD=0.75

# ================================
# UI 配置
# ================================
UI_WINDOW_WIDTH=1400
UI_WINDOW_HEIGHT=900
UI_THEME=dark
```

### 4.2 配置文件

支持 YAML 和 JSON 格式的配置文件：

```yaml
# config.yaml
model:
  default_model: openai
  temperature: 0.7
  max_tokens: 2000

memory:
  db_path: memory.db
  vector_dim: 1536
  max_short_term_items: 100

cognitive:
  reasoning_depth: 3
  enable_meta_cognition: true

evolution:
  auto_evolve: true
  evolution_interval: 3600
```

使用配置文件启动：

```bash
python -m hyperbrain.app --config config.yaml
```

### 4.3 模型选择策略

| 场景 | 推荐模型 | 说明 |
|------|----------|------|
| 通用对话 | GPT-4 / Claude-3 | 能力强，成本高 |
| 代码任务 | GPT-4 / Gemini Pro | 代码理解好 |
| 长文本 | Claude-3 | 上下文窗口大 |
| 本地运行 | Ollama/llama2 | 免费，隐私好 |
| 快速响应 | GPT-3.5 | 速度快，成本低 |

## 5. 常见问题解答

### Q1: 启动时提示 "GUI 模式不可用"

**原因**: PyQt6 未安装

**解决**:
```bash
pip install PyQt6>=6.6.0
```

### Q2: 模型调用失败，提示 API Key 错误

**原因**: API Key 未配置或无效

**解决**:
1. 检查 `.env` 文件中的 API Key
2. 确认 Key 是否有效（可在官网测试）
3. 检查网络连接

### Q3: 系统响应很慢

**原因**: 可能是模型响应慢或本地资源不足

**解决**:
1. 切换到更快的模型（如 GPT-3.5）
2. 检查系统资源占用
3. 降低认知配置中的推理深度
4. 使用本地 Ollama 模型

### Q4: 记忆数据存储在哪里？

**回答**:
- SQLite 数据库: `hyperbrain/memory.db`
- 向量数据: `hyperbrain/data/vectors/`
- 日志文件: `hyperbrain/logs/`

### Q5: 如何备份记忆数据？

**解决**:
```bash
# 备份数据库
copy hyperbrain/memory.db backup/memory.db.backup

# 备份向量数据
xcopy hyperbrain\data\vectors backup\vectors /E /I
```

### Q6: 如何清理旧记忆？

**解决**:
1. 在设置中调整遗忘参数
2. 手动触发遗忘机制
3. 删除数据库文件重新初始化

### Q7: 支持哪些大模型？

**回答**:
- OpenAI: GPT-4, GPT-3.5-turbo
- Anthropic: Claude-3 Opus/Sonnet/Haiku
- Google: Gemini Pro
- 本地: Ollama (llama2, mistral, codellama 等)

### Q8: 如何切换主题？

**解决**:
1. GUI 模式: 视图菜单 -> 主题切换
2. 配置文件: `UI_THEME=dark` 或 `UI_THEME=light`

### Q9: 系统占用内存过高怎么办？

**解决**:
1. 降低记忆容量配置
2. 关闭不必要的可视化面板
3. 定期清理缓存
4. 重启系统释放内存

### Q10: 如何开发插件？

**回答**:
参考 [技术文档](technical_documentation.md) 中的扩展接口说明，实现对应的接口即可。
