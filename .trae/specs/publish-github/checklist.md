# Checklist

- [x] 项目根目录已存在 `.git` 或已成功初始化
- [x] `.gitignore` 已正确配置并排除敏感文件
- [x] `git status` 显示没有未跟踪的敏感文件（如 config.yaml、*.db）将被提交
- [x] 已创建包含当前所有有效变更的 commit
- [x] GitHub remote 已配置并可访问
- [ ] 本地分支已成功推送到 GitHub（git push 因网络/认证问题失败，已提供替代脚本）
- [ ] 通过浏览器或 GitHub API 验证仓库文件已上传（README、.gitignore、发布脚本已上传，完整代码待推送）
